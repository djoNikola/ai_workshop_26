# AI in Everyday Company Workflows

This repository is the shared workspace for a five-person workshop on putting
AI to practical use in everyday company tasks. The goal is to identify one
useful workflow, prototype an AI-assisted improvement, and agree how to
evaluate it responsibly.

## Workshop outcome

Choose a repetitive or time-consuming task, map how it works today, and build
a small prototype that helps with one part of it. Possible starting points
include summarizing meeting notes, drafting routine updates, sorting incoming
requests, or finding information in approved company documents.

## Working as a team of five

Share these responsibilities across the team; pair up where useful:

1. **Workflow lead** — describe the current task, its users, and pain points.
2. **Use-case researcher** — gather examples and define what a good result looks like.
3. **Prototype builder** — coordinate the implementation of the AI-assisted step.
4. **Risk and data reviewer** — check privacy, data access, accuracy, and human oversight.
5. **Tester and facilitator** — try realistic examples, capture feedback, and present the outcome.

## Suggested workshop flow

1. Select one task and identify who performs it and why it matters.
2. Map the current steps and choose a narrow, measurable improvement.
3. Sketch and build a prototype using only appropriate, non-sensitive example data.
4. Test it against realistic cases, including mistakes and uncertain results.
5. Share what worked, what needs human review, and what should happen next.

## Principles

- Keep a person responsible for reviewing consequential outputs.
- Do not put confidential, personal, or customer data into unapproved AI tools.
- Check outputs for accuracy, bias, and missing context before using them.
- Compare the prototype with the existing workflow; AI is useful only if it improves the task.
